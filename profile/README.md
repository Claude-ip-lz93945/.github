<p>Claude住宅IP池和机房IP这两类资源，经常被放在一起比价格，其实它们解决的不是同一个问题。机房IP胜在稳定和速度，住宅IP胜在出口属性接近真实家庭网络，混着比很容易得出错误结论。</p>

<p>第一项对比是出口属性。机房IP的归属通常明确指向数据中心，住宅IP的归属指向家庭宽带。这个差异不带好坏判断，但在需要看起来像普通用户的场景里，它直接决定方案能不能用。</p>

<p>第二项对比是稳定性。机房IP的可用性和延迟普遍更好，波动小；住宅IP受制于家庭网络的实际情况，波动更明显。要求长时间稳定连接的场景，机房IP的优势很明显。</p>

<p>第三项对比是速度。机房线路带宽充足、路由直接，住宅线路要经过家庭宽带那一段，速度上限通常更低。对延迟敏感的批量任务，这个差距是能感觉到的。</p>

<p>第四项对比是成本结构。机房IP按量便宜、单价低；住宅IP单价高，但能做的事情不一样。单纯比单价没有意义，要比完成同一个任务的总花费。</p>

<p>第五项对比是维护成本。机房IP相对省心，住宅IP要定期核验归属、处理波动、维护池子状态。这部分人力成本在选型阶段经常被低估，用起来才发现占了很大一块。</p>

<p>实际用起来，两类资源更多是组合关系而不是替代关系。常见做法是把大部分稳定负载放在机房IP上，把需要真实出口属性的少量任务放到住宅IP上，各做各擅长的事。</p>

<p>组合的时候要注意隔离。两类出口不要混在同一个账号上频繁切换，切换本身就会带来额外的异常信号。建议按任务类型固定出口类型，别在同一任务里来回换。</p>
